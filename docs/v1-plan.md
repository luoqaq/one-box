# OneBox V1 产品与技术方案

更新日期：2026-11-18  
平台：macOS 菜单栏 App  
证据来源：[平台能力调研](research/desktop-platform-evidence.md)、[MyGo / NSH / NSGo 评估](research/mygo-nsh-evaluation.md)
详细设计：[原生架构设计](architecture.md)
实现现状：[PROJECT_MEMORY.md](../PROJECT_MEMORY.md)

## 首屏结论

推荐做 **原生 macOS App：SwiftUI + AppKit + ScreenCaptureKit**，系统最低版本设为 **macOS 15.2+**。

原因是 V1 的难点不在普通 UI，而在系统能力闭环：剪贴板变更检测、图片表示转换、屏幕录制权限、跨屏矩形截图、选区遮罩和标注导出。Tauri / Electron 都有能力缺口，最后仍要写原生桥接；第一版不值得再背一层 Web 运行时。

MyGo 可以作为备选试验方案：它已覆盖 tray、全局快捷键和富剪贴板读写，但没有公开的剪贴板变更监听和屏幕捕获 API，仍要写 Swift native module。NSH / NSGo 对 V1 不如 MyGo 直接，暂不作为主线。

## V1 范围

### 0. 工具箱汇总入口

**做什么**

- 菜单栏图标点击后默认打开工具箱。
- 展示全部工具，支持分类、搜索、固定和最近使用。
- 提供工具详情、使用次数、快捷键和权限状态。
- 新增工具时通过工具注册表接入，不改变工具箱框架。

**明确不做**

- V1 不做第三方插件系统，只做内置工具注册。
- 不做云端工具市场。

### 1. 剪贴板历史

**做什么**

- 监听 `NSPasteboard.general.changeCount`，发现变化后保存新条目。
- 支持文本和图片。
- 文本保留纯文本；图片统一转为 PNG 存储并生成缩略图。
- 历史支持搜索、查看、复制回剪贴板、置顶、单条删除、清空。
- 应用自写剪贴板时抑制回环，不把“复用历史”重复记成新历史。

**明确不做**

- 不做跨设备同步。
- 不承诺保留源应用的所有剪贴板表示；例如 RTF、HTML、文件 URL、多对象剪贴板可作为后续扩展。
- V1 默认不做自动向目标应用发送 `Cmd+V`；用户点击复用后手动粘贴。自动粘贴涉及 PostEvent / 辅助功能权限，放到后续版本。

**历史数据模型**

- `id`：UUID
- `kind`：text / image
- `content`：文本内容
- `imageFile` / `thumbnailFile`：图片与缩略图文件
- `hash`：用于去重
- `createdAt`、`lastUsedAt`、`useCount`
- `pinned`

默认保留 500 条或 30 天；置顶条目不参与自动清理。

### 2. 区域截图与标注

**做什么**

- 全局快捷键打开截图。
- 在多个显示器上展示全屏选区遮罩，支持拖拽框选和 Esc 取消。
- 用 ScreenCaptureKit 截取选区；跨屏选区按显示器拆分捕获，再按 point/pixel 比例裁剪合并。
- 标注支持：箭头、文字、矩形、打码。
- 输出支持：复制到剪贴板、保存 PNG 文件。
- 截图完成后可进入“最近截图”列表，允许重新复制或打开文件。

**明确不做**

- 不做滚动长截图、OCR、贴图、录屏。
- 不做 Windows 截图适配。
- 不默认隐藏 macOS 的屏幕捕获提示边框；该能力需要单独授权，V1 不承诺。

## 推荐架构

```text
OneBox
├─ App / MenuBar          菜单栏入口、偏好设置、快捷键注册
├─ HotKeys                热键规格与匹配
├─ ToolRegistry           工具描述、分类、固定状态
├─ ToolLauncherUI         工具箱、搜索、分类、最近使用和工具详情
├─ ClipboardHistory       changeCount 轮询、内容采集、去重、自写抑制
├─ ClipboardStore         本地元数据存储、图片文件、缩略图、清理策略
├─ OneBoxUI               工作台 UI（剪贴板 / 截图 / 设置 / 标注）
├─ ScreenCapture          屏幕权限、跨屏选区、ScreenCaptureKit 捕获
├─ Annotation             箭头/文字/矩形/打码与 PNG 渲染导出
├─ CaptureStore           最近截图记录与复制/打开操作
└─ ColorPicker            屏幕取色与色值格式化
```

### 3. 屏幕取色器（已纳入实现）

**做什么**

- 全局快捷键或工具箱快捷动作进入全屏取色。
- 吸取屏幕像素，复制 HEX / RGB / OKLCH。
- 作为可启用工具注册；默认关闭，不强制占用热键。

**明确不做**

- 不做色板管理、对比度检测、设计系统同步。

### 技术选择

- **UI**：SwiftUI；遮罩、窗口层级、菜单栏等细节用 AppKit 补足。
- **剪贴板**：`NSPasteboard` 官方 API。
- **截图**：`ScreenCaptureKit`；矩形便利接口 `SCScreenshotManager.captureImage(in:)` 需要 macOS 15.2+。
- **存储**：SwiftData / SQLite 存元数据；图片和缩略图放 `Application Support` 目录，不把图片直接塞数据库。
- **快捷键**：原生注册全局快捷键，允许用户在设置里修改，避免假定某个组合键一定未被占用。

## 权限与隐私

- 截图需要屏幕录制权限；App 首次触发截图时引导用户到系统设置授权，并在授权后引导重启应用。
- 剪贴板可能包含密码、令牌、证件和聊天内容。V1 数据只落盘在本机 `Application Support`，并提供清空历史。
- macOS 15.4+ 有新的剪贴板访问行为 API，但“正式系统默认策略”仍需在当前 macOS 27.2.1 实机确认；不能只按文档推断后台读取一定不弹窗。
- 自动粘贴不是 V1 能力，因此 V1 不依赖辅助功能权限。

## 验收标准

1. 点击菜单栏图标默认进入工具箱，可搜索、按分类筛选并固定工具。
2. 在浏览器、聊天工具、预览等应用中复制文本和图片后，1 秒内进入历史。
3. 同一张图片能多次从历史复制到目标应用；透明背景和尺寸保持一致。
4. 连续复用同一条历史不会生成重复条目。
5. 所有显示器可用快捷键唤起截图；选区、取消、跨屏截图结果与屏幕所见一致。
6. 截图添加箭头、文字、矩形、打码后，复制到聊天工具仍清晰可辨。
7. 拒绝屏幕录制权限时，界面明确提示原因和开启路径。
8. 退出并重启 App 后历史仍保留；清空历史会同步删除图片文件。

## 实施顺序

1. 初始化 SwiftUI/AppKit macOS 项目，完成菜单栏外壳和偏好设置入口。
2. 做工具注册表和工具箱，完成分类、搜索、固定和工具详情。
3. 做剪贴板采集与本地存储，先完成文本，再接图片。
4. 完成历史列表、搜索、复制回剪贴板、置顶和删除。
5. 接 ScreenCaptureKit 权限与跨屏选区截图。
6. 做标注编辑器和 PNG 导出。
7. 做最近截图、快捷键设置、存储清理和权限错误处理。
8. 用真实应用回归验收；通过后打包成本地可运行 App。

## 关键风险

- **剪贴板隐私策略**：需要先在当前系统验证后台读取、类型探测、拒绝后表现和授权持久性。
- **图片兼容性**：PNG/TIFF 之外可能存在自定义表示；V1 只承诺常见图片内容，不承诺完整还原源剪贴板对象。
- **跨屏截图**：Retina、混合缩放、旋转屏和热插拔需要实机验证；不能只测单屏。
- **自动粘贴后置**：即使 V2 做，也要把“写回剪贴板”和“向目标应用发送按键”作为两个权限分别验证。
